# Sjoerd van der Veen - Website Development Instructions

## Project Overview

Luxe website voor Sjoerd van der Veen Bestrating & Hovenierswerk met:

- Modern luxe design
- Duidelijke scheiding bestratingswerk vs hovenierswerk
- Afspraak/boekingssysteem
- TikTok integratie
- Responsive design

## Designstijl

### Kleurenpalet

- **Donkergroen**: #2d5016 (premium accent)
- **Beige/Zand**: #e8dcc4 (warm, natuur)
- **Gebroken wit**: #faf8f5 (background)
- **Antraciet**: #2c2c2c (tekst, contrast)
- **Brons/Goud accent**: #b8860b (subtiel)
- **Wit**: #ffffff (clean)

### Typografie

- **Headings**: Playfair Display (serif, luxe)
- **Body**: Inter (modern, clean)
- **Accenten**: Handgeschreven lettertype voor woorden als "Hovenier", "Vakwerk buiten" (subtiel)

### Design Principes

- Modern luxe uitstraling
- Veel witruimte
- Subtiele schaduwen
- Afgeronde hoeken
- Elegant, niet schreeuwerig
- Premium ambachtelijk gevoel

## Technische Vereisten

### Bestanden

- index.html (herzien)
- style.css (herzien met luxe kleurenschema)
- script.js (herzien met boekingssysteem)
- Eventueel: /assets map voor afbeeldingen

### JavaScript Functionaliteit

- Mobile navigation toggle
- Form validation
- Booking system logic
  - Beschikbare datums/tijden
  - Categorieselectie afhankelijk maken
  - Data opslaan in object
  - Bevestiging tonen
- LocalStorage voor formulierdata
- Smooth scrolling

### CSS Features

- CSS variables voor kleuren, spacing, fonts
- Responsive design (mobile, tablet, desktop)
- Subtle hover-effecten
- Geen drukke animaties
- Fast loading

### JavaScript Object Structure

```javascript
const booking = {
  mainCategory: "bestratingswerk" // or "hovenierswerk",
  klustType: "grondwerk",
  appointmentType: "kennismaking",
  date: "2026-06-15",
  time: "14:30",
  contact: {
    name: "Jan Jansen",
    phone: "+31612345678",
    email: "jan@example.com",
    location: "Amsterdam",
    address: "Hoofdstraat 1, Amsterdam (optioneel)",
    preference: "whatsapp" // or "phone", "email"
  },
  description: "Ik wil een terras aangelegd hebben...",
  timestamp: "2026-06-10T15:30:00Z"

```

### Beschikbaarheidssysteem

- Fake data in JavaScript array
- Beschikbare datums: komende 14 dagen
- Beschikbare tijden: 09:00, 10:30, 13:00, 14:30, 16:00
- Comment toevoegen voor toekomstige Google Calendar API koppeling
